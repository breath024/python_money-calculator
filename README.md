# 입출금 계산기

들어오고 나간 돈을 한 줄로 입력하면 연도별 엑셀 장부에 바로 적어주는 데스크톱 앱.
`PyQt6`로 창을 띄우고 `openpyxl`로 엑셀을 쓴다.

## 만든 이유

가계부 앱은 켜고, 항목 고르고, 금액 넣고, 저장까지 손이 많이 간다. 쓰는 게 귀찮아서
안 쓰게 되니까 **입력을 한 줄로 줄이는 것**만 목표로 잡았다.
그리고 결과를 앱 안에 가두지 않고 엑셀 파일로 남겼다. 나중에 이 앱을 안 쓰게 돼도
장부는 그대로 남고, 엑셀에서 직접 고쳐도 된다.

## 쓰는 법

아래 입력칸에 `금액/내용`을 넣고 엔터. 오른쪽 콤보박스에서 입금/출금을 고른다.

| 입력 | 하는 일 |
|---|---|
| `10000/월급` | 오늘 칸에 10,000원을 입금(또는 출금)으로 기록 |
| `.` | 오늘까지의 입금액·입금처·출금액·출금처·잔액 |
| `,` | 현재 잔액 |
| `?` | 입력 형식 안내 |

같은 날 두 번 넣으면 금액은 더하고, 내용은 `월급, 용돈`처럼 이어 붙인다.
금액이 양수인지, 내용이 25자 이하인지, 슬래시가 정확히 하나인지를 각각 따로 걸러
어디가 틀렸는지 다른 문구로 알려준다.

## 엑셀을 어떻게 만드나

`xl.py`는 그 해의 `입출금내역_YYYY.xlsx`가 없으면 통째로 만들어 놓고 시작한다.

- 1~12월 시트를 만들고 각 시트에 **그 달의 날짜를 하루씩 미리 깔아둔다.**
  그래서 기록할 때 행을 찾을 필요가 없다 — `날짜 + 1`이 곧 행 번호다.
- 잔액 열은 값이 아니라 **수식**(`=B3-C3+F2`)으로 넣는다. 엑셀에서 한 칸을 고치면
  아래가 전부 따라 움직인다.
- 달이 바뀌는 자리는 앞 달의 마지막 행을 참조한다(`='1월'!F32`).
- 해가 바뀌면 작년 파일의 12월 잔액을 **외부 참조**로 물어온다. 작년 파일이 없으면
  `Set.txt`에 적어둔 금액을 시작 잔액으로 쓴다.

읽을 때는 `data_only=True`로 다시 열어서 수식이 아니라 계산된 값을 가져온다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `main.py` | 진입점. `ui.main()` 한 줄 |
| `ui.py` | PyQt6 창, 입력 파싱, 명령 분기 |
| `xl.py` | 엑셀 생성·기록(`add`/`minus`)·조회(`rmoney`/`mlog`) |
| `Set.txt` | 첫 해에 쓸 시작 잔액 |

## 실행

```
pip install PyQt6 openpyxl
python main.py
```

## 지금 다시 보면

- 엑셀 경로가 `xl.py` 안에 **절대경로로 11번 하드코딩**돼 있다. 폴더를 옮기면 바로 깨진다.
  상수 하나로 뺐어야 했다
- `,` 명령이 `xl.rmoney`를 **괄호 없이** 참조한다. 잔액 대신 함수 객체가 찍힌다
- `import xl` 만으로 파일 생성과 저장이 일어난다. 모듈 최상위에 그 코드를 뒀기 때문인데,
  함수로 감싸고 필요할 때 불렀어야 했다
- 기록할 때마다 통합문서를 열고 저장한다
- 빨간 마이너스 서식(`minus_style`)을 만들어 놓고 쓰지 않았다
- `__pycache__`를 커밋해뒀었다
